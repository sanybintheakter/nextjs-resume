# Next.js Resume

## Live Demo

## Description
This project is a personal resume website built using Next.js and Tailwind CSS.  
It showcases my education, experience and skills in a clean and responsive layout.

## How to Run
- npm install  
- npm run dev  
- Open in browser:
http://localhost:3000
